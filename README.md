# AI-Driven Student Performance Prediction System

A Python and Streamlit-based machine learning system that predicts student performance using:

* Attendance
* Internal Marks
* Assignment Marks
* Study Hours
* Previous Marks

### Features

* 🔐 User Login & Registration
* 🔮 Performance Prediction
* 📊 Performance Score
* 🟢 Good / 🟡 Average / 🔴 At Risk
* 💡 Recommendations
* 📋 Student Records

### Technologies

Python • Streamlit • Pandas • Scikit-learn • SQLite

### Run

```bash
pip install streamlit pandas scikit-learn
streamlit run app.py
```
